# Project Lockdown

HTML5 Canvas로 만든 탑다운 액션 프로토타입입니다. 메인 메뉴에서 테스트방, 룸 클리어링 맵(연구소·격리 물류동), 스프라이트 확인방을 열 수 있습니다. 키보드와 마우스를 사용합니다.

## 조작

| 입력 | 기능 |
| --- | --- |
| WASD / Shift / C | 이동 / 달리기 / 앉기 |
| 마우스 왼쪽 / 오른쪽 | 공격 / 정조준 |
| R / F | 재장전 / 조준점 아래의 아이템과 상호작용 |
| 1, 2 / E / Q / X | 주무기 / 보조무기 / 근접무기 / 주먹 |
| Space / G | 근접공격 또는 가드 / 수류탄 |
| Tab / Esc | 인벤토리 / 일시정지 |

## 실행과 배포

이 폴더의 `index.html`과 `system-combat.js`를 같은 폴더에 두고 브라우저에서 `index.html`을 엽니다. GitHub Pages에 게시하려면 이 폴더의 내용물을 저장소 루트에 올리고, 저장소 설정의 **Pages → Deploy from a branch → system-test-v2 → / (root)**를 선택합니다.

메뉴 이미지와 총기·플라즈마 샘플을 포함합니다. SAM 음성과 일부 근접·탄착 샘플은 제외되어 있습니다.
